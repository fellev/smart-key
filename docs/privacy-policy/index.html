SmartKey Privacy Policy

Effective date: October 24, 2026

This policy explains how the SmartKey Android application handles information. For privacy questions, contact the publisher using the contact details at the end of this policy.

Information stored on your device

To pair with doors, SmartKey stores door identifiers, a device identifier, derived cryptographic keys, door labels, and pairing timestamps. If you configure Home Assistant, the app also stores the server URL, access token, service, and entity ID you provide. The app does not send analytics or crash reports to the publisher; crash details, if generated, are kept locally on your device.

SmartKey encrypts these preferences using Android Keystore-backed encrypted preferences. If encrypted credential storage cannot be initialized, the app currently falls back to app-private preferences, which are not encrypted by that fallback. Android app-private storage remains subject to the security of your device.

Bluetooth and door hardware

SmartKey uses Bluetooth Low Energy to pair with compatible door hardware and exchange presence, pairing, and authentication messages. The app processes these communications to provide the door-key features. Bluetooth data is exchanged with your nearby door hardware; the publisher does not receive it.

Optional Home Assistant connection

If you configure Home Assistant, SmartKey sends an HTTPS request to the URL you supply when the door requests an open action. The request includes the configured service and entity ID and uses the access token you supplied for authorization. The request is sent directly to that Home Assistant server, not to a publisher-operated server. The server operator may receive and retain request data under their own practices; review the privacy terms for that server, especially if it is operated by a third party.

Sharing, collection, and advertising

The publisher does not operate an app backend, receive app usage data, sell personal information, or use advertising or analytics SDKs. Information is shared only with the compatible door hardware you pair and, if you enable the integration, the Home Assistant server you configure.

This policy is hosted by GitHub Pages. When you visit this page, GitHub may process technical request information under its own privacy policy. The page does not use tracking scripts or advertising.

Retention and deletion

You can remove paired door credentials in the app. The generated device identifier and Home Assistant settings remain on your device until you change the settings, clear SmartKey's app data, or uninstall the app. Information already sent to a door or Home Assistant server is subject to that recipient's retention practices.

Children

SmartKey is a utility for operating compatible door hardware and is not designed for children.
